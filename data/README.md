# Data folder

This repository does **not** redistribute individual-level NHATS public-use files.
NHATS public-use files and documentation should be obtained directly from the NHATS website or ICPSR/NACDA under the applicable data-use terms.

The `data/derived/` folder contains de-identified derived summary tables used to reproduce the submitted tables and figures.
These files are sufficient for the one-click figure/table regeneration script in this repository, but they are not a substitute for the original NHATS public-use files.
