# Data and code availability

- Public-use NHATS data and documentation are available from the NHATS website and the ICPSR/NACDA repository.
- This study used only de-identified public-use files and did not use restricted-use files or linked Medicare claims data.
- Raw NHATS public-use data are not redistributed in this repository.
- Reproducible scripts and de-identified derived summary inputs for regenerating the submitted tables and figures are included.
